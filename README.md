# hk.net Knowledge Management System

A project developed for Applied Software Engineering at the University of West London (AY2025-26).

## What it does

The system allows authorised users to search and retrieve archived project emails, view metadata, download attachments, and subscribe to project updates.

## What's included

- UML diagrams — Use Case, Class, Sequence, and Component
- Design patterns — Observer Pattern for notifications, Facade Pattern for system control
- Business logic enforced using Object Constraint Language (OCL)
- Unit tests written in JUnit 5
- A risk register covering data quality, performance, and security

## System services

- **AuthService** — handles user login and access control
- **ProjectService** — manages project data and subscriptions
- **EmailService** — searches and retrieves emails
- **AttachmentService** — handles file downloads
- **StorageService** — manages exports for auditing

## Technologies

- Java
- JUnit 5
- Draw.io
- Maven

## Folder structure

- `src/` — Java source code
- `tests/` — unit tests
- `docs/` — UML diagrams and risk analysis
